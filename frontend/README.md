# Frontend - Afro Word Buzz 🎬

Application React pour Afro Word Buzz

## Installation

```bash
cd frontend
npm install
```

## Démarrage

```bash
npm start
```

L'application ouvrira sur `http://localhost:3000`

## Build

```bash
npm run build
```

## Structure du projet

```
src/
├── components/     # Composants réutilisables
├── pages/          # Pages principales
├── services/       # Appels API
├── styles/         # Fichiers CSS
├── App.js          # Composant principal
└── index.js        # Point d'entrée
```

## Variables d'environnement

Copier `.env.example` en `.env.local` et configurer :

```env
REACT_APP_API_URL=votre_url_api
```
